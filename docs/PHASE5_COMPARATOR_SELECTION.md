# Phase 5 comparator selection and overlap review

Reviewed 2026-10-14; [#30](https://github.com/siamakenna/perturb-LM/issues/30), [#52](https://github.com/siamakenna/perturb-LM/issues/52), [#55](https://github.com/siamakenna/perturb-LM/issues/55). Recommendation, not execution authorization. No encoders were added, no checkpoints downloaded and no pretrained inference or Biowulf jobs run in Phase 5. DINOv2 is off the critical path; its implementation is retained.

## Decision

Keep TF-IDF and CellProfiler as essential controls, with random/shuffled and gene-lookup baselines. Preserve historical BiomedBERT evidence as an anchor. Once informative queries and endpoints are approved, prioritize **one** retrieval-specialized text comparator (MedCPT); use BioLORD only if the approved endpoint tests functional/concept descriptions. Defer SapBERT and SciBERT unless their distinct hypotheses become necessary. Drop BlueBERT from the immediate plan. Image models await image mapping, independent evaluation and checkpoint-overlap review; DINOv2 is an optional rebuttal baseline.

A model cannot recover distinctions absent from its input. Running more encoders on eight V2 strings would test how they encode categories, not establish treatment-level biological understanding.

Historical M0 is gene-aware; CellCLIP's metadata-rich published-prompt condition is separate and documented as pending.

## Overlap gate before future model runs

For each exact checkpoint, lock training/fine-tuning dataset releases, study aliases (including CPJUMP1/cpg0000-jump-pilot), plate IDs, perturbations, channel/site lineage and any split provided by the authors. Check repeated imaging and derived crops as potential duplicates. An image hash mismatch or different dataset name does not imply an independent biological sample. If exact manifests are unavailable, record overlap as unresolved and avoid external-validation claims; a contaminated model may still be useful as an explicitly in-domain comparator.

For text models, distinguish knowledge of genes/targets from exposure to paired morphology. Audit supplied annotations and text sources as well as weights. TF-IDF and a gene lookup control help reveal identity advantages. Keep pooling variants as sensitivity settings, not extra model families. Resolve scientific need before paying inference or integration cost.
